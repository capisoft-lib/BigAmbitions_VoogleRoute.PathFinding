## Rebuild pipeline

```powershell
python tools/generate_enhanced_route_graph.py <beta1-waypoints.csv> data/big_ambitions_enhanced_routes.csv docs/big_ambitions_enhanced_route_graph.svg

python tools/migrate_legacy_manual_edges.py `
  <pre-beta-enhanced-routes.csv> `
  <pre-beta-waypoints.csv> `
  <beta1-waypoints.csv> `
  data/big_ambitions_enhanced_routes.csv

python tools/preprocess_bridge_merge.py --no-svg
python tools/preprocess_center_deck_merge.py
python tools/preprocess_center_deck_elevation.py --backup <pre-center-deck-backup.csv>
python tools/preprocess_1703_collapse.py

powershell -NoProfile -File tools/sync-route-data.ps1 -ModRoot "..\.."
dotnet test Tests/VoogleRoute.Pathfinding.Tests.csproj -c Release
```

Why the migration step exists: beta 1.0 reordered the Gley waypoint indices even where road geometry was unchanged. The migration tool resolves the legacy hand-authored corrections by old waypoint identity and nearest same-named beta waypoint, then rewrites those edges with beta indices. Center-deck and Road 1703 edges are regenerated by their dedicated preprocessors.
